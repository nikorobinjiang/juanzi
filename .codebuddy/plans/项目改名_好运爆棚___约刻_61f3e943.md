## 产品概述
将项目品牌名称从「好运爆棚」统一改为「约刻」，覆盖所有用户可见的品牌展示位置（页面标题、登录/注册品牌区、聊天页头部与欢迎语）及内部文案（JS/CSS 注释、README、Excel 导出表头、APP_NAME 配置）。

## 核心功能
- 页面标题统一为「约刻」（登录、注册、聊天、图片生成四个页面）
- 登录/聊天页品牌名称与欢迎语改为「约刻」，保留 🍀 logo
- 副标题「约课 · Excel · 好运」去掉「好运」，变为「约课 · Excel」
- Excel 导出表头、README、copy.env 的 APP_NAME 同步改为「约刻」
- 服务器 .env（git 外）的 APP_NAME 需手动改为「约刻」

## 技术方案
纯文本品牌替换任务，不涉及逻辑改动，采用精确字符串替换策略，避免误伤。

- 共 10 个文件、14 处「好运爆棚」+ 2 处副标题「好运」需处理，已逐一搜索确认无其他遗漏
- `config/app.php` 的 `name` 从 env 读取，无需改代码；本地 `copy.env` 与服务器 `.env` 的 `APP_NAME` 改为「约刻」后框架级名称生效
- 部署流程沿用既有约定：本地 git push → 服务器 git pull → `php artisan config:clear` → 重启 worker（.env 的 APP_NAME 改动无需重启 worker，但配置缓存清理后生效）
